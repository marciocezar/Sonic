# ADR 0006 — Licenciamento e assets
Decisão: builds contêm apenas conteúdo próprio (Lab Zone, arte/sons gerados). Dados derivados da ROM ficam em
`private/` e só são usados localmente (Fidelity de laboratório). Parâmetros funcionais (constantes, hitboxes) são
reimplementados como fatos — decisão técnica sujeita a revisão jurídica. Nenhum nome/ID sugere afiliação oficial.
